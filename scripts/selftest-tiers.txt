# scripts/selftest-tiers.txt — WHERE each self-test runs. One row per script that carries a self-test.
# (feat_harness_self_tests_follow_one_flag_contract_and_a_tier_manifest_that_verify_runs)
#
#   <script path><TAB><tier>[<TAB><reason>]
#
#   verify   runs in scripts/verify.sh's self-test step on every PR (the step runs EXACTLY the rows of
#            this tier — `check-selftests-are-invoked.sh --list` — and fails on an empty list, so the
#            step can never pass having run nothing)
#   stack    runs only in a verify that has a stack up (a self-test that needs docker, a database or
#            the app). It is GATED, not exempt: a narrower promise about WHERE, never a decision not to run.
#   nowhere  runs in no tier — ONLY with a reason in the third column (an exemption without a reason
#            is `ungated`, and ungated fails the build). The usual reason: the file is a sourced
#            library whose arms run inside a parent script's self-test.
#
# ⚠ THE MANIFEST RECORDS INTENT; AN ACTUAL INVOCATION IS EVIDENCE. check-selftests-are-invoked.sh
# credits a script as gated only when something INVOKES it with a self-test flag (comments stripped,
# the script's own file excluded, a prose mention never counts). A stale `nowhere` row cannot
# suppress a real gate, and a `verify` row for a script nothing runs is caught the moment the step
# runs the list. Every script's flag goes through scripts/lib/selftest-flag.sh (selftest_is_flag /
# selftest_requested): check-selftest-flag-contract.sh refuses a hand-parsed flag, because a
# mistyped `--slef-test` must exit 2, never fall through to the script's real action.
